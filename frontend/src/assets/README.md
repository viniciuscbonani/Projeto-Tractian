# Referências visuais

- `sensor-centered-desktop.avif`: imagem do sensor fornecida pelo usuário.
- `icons/`: SVGs oficiais de https://brand.tractian.com/assets/icons/Custom/, consultados em 6 de setembro de 2026. Os nomes originais permanecem nos metadados dos arquivos. As cores são aplicadas por máscara CSS, preservando os desenhos.
- `fonts/`: Inter (400, 500, 600) e Inter Tight (600, 700, 800), obtidas via Google Fonts. Fontes hospedadas localmente para evitar requisições externas em produção.
- Guia usado para a composição, paleta e tipografia: https://brand.tractian.com/.

A imagem do sensor está preservada como material de referência e não é carregada pela interface operacional. As evidências são agrupadas a partir das fontes efetivamente consultadas, e os metadados do ativo vêm da API existente.
