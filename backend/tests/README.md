# Testes do backend

- `unit/`: schemas, políticas, gates e roteamento sem rede;
- `integration/`: cliente e tools contra a API local;
- `contract/`: aderência ao OpenAPI e preservação dos envelopes;
- `e2e/`: execução completa do backend sem o frontend.

Os evals do comportamento agêntico ficam no diretório raiz `evals/`.
