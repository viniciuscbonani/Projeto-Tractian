# Agentes especializados

Prompts e adaptadores dos cinco papéis ativos: classificador, agente de fontes, investigador, juiz
e redator. O agente de fontes planeja e seleciona somente consultas GET; o investigador sintetiza
as evidências e o juiz emite objeções estruturadas sem controlar o grafo. Um compilador local
valida essas objeções, pode devolver uma vez à etapa responsável ou substituir conteúdo contestado
por uma resposta conservadora validada. Nenhuma etapa executa ações no sistema industrial.
