# Testes agênticos

Asserções de regressão sobre o resultado consolidado e, quando necessário, sobre o histórico
de checkpoints. A ordem total de tools não deve ser exigida quando houver trajetórias
alternativas válidas.

Também validam o dataset versionado: contagens, três variantes por cenário, isolamento por ativo
e separação física entre entradas e gabarito.
